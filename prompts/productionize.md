Productionize: $@

Identify the system type and deployment model. Assess the actual gaps in correctness, tests, configuration, secrets, observability, recovery, deployment, rollback, performance, data integrity, compatibility, versions, and ownership. Rank by impact; implement appropriate in-scope changes without blindly adding infrastructure. Validate locally and distinguish staging or production checks still required.
