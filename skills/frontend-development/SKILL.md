# Frontend development

- Inspect the existing framework, components, tokens, state handling, routing, API client, build tools, and test conventions. Reuse established patterns.
- Make loading, empty, error, and success states explicit for changed flows. Keep server contracts and client validation aligned.
- Preserve keyboard access, labels, focus behavior, contrast, and responsive behavior where the interface requires them.
- Avoid hidden global state and unnecessary dependencies. Keep data fetching, presentation, and reusable domain behavior distinct when useful.
- Test meaningful user behavior at the cheapest layer, then validate critical flows in the browser when relevant. Check build and accessibility tooling already used by the project.
