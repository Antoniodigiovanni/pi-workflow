# Lesson record template

Copy this to a dated Markdown file in your Pi lessons directory or the relevant project. Keep identifiers and data non-sensitive.

```markdown
# Short lesson title

- Date and context:
- Mistake, failure, or repeated correction:
- Evidence and root cause:
- Reusable lesson (one precise decision):
- Proposed destination: project code/test | project AGENTS.md | global AGENTS.md | domain skill | prompt | extension/tool
- Regression test added? Yes/No; location or reason:
- Review status: proposed | accepted | rejected | applied
```
